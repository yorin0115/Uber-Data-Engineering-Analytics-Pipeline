# Uber-Data-Engineering-Analytics-Pipeline
End-to-End Data Pipeline with GCP, Mage, BigQuery & Looker Studio

---

## Introduction
The goal of this project is to build an end-to-end data pipeline for Uber data using various tools and technologies, including GCP, Python, Mage, SQL, BigQuery, and Looker Studio, to perform data extraction, transformation, loading, and visualization.

## Project goals
* **Build an End-to-End Pipeline:** Build an end-to-end data pipeline from GCP Cloud Storage → Mage → BigQuery → Looker Studio.
* **Data Cleansing & Modeling:** Use Python and Pandas for data cleaning, format conversion, and data transformation, and build fact and dimension tables.
* **Data Integration & Visualization:** Use BigQuery and SQL to integrate data and create a visualization dashboard with Looker Studio.
* **Troubleshooting & Technical Problem Solving:** Troubleshoot VM and Python environment setup, Mage compatibility issues, Python package version conflicts, and performance and memory issues caused by large-scale data processing.

## Dataset Used
This project uses the public [NYC TLC Trip Record Data](https://www.nyc.gov/site/tlc/about/tlc-trip-record-data.page), which contains trip distance, locations, timestamps, and fare details.
